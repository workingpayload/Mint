# Source changes

Existing project files were reused. Generated `bin`, `obj`, `.vs`, test output, and `artifacts` are excluded from source control.

## Modified

- `CreateFile.slnx`: x64/ARM64 configurations, native project, test project.
- `src/CreateFile.App/CreateFile.App.csproj`: pinned WinUI component/runtime/MSIX packages, unpackaged build defaults, architecture configuration.
- `src/CreateFile.App/App.xaml.cs`: activation arguments, settings load and commit, themes.
- `src/CreateFile.App/MainWindow.xaml` and `.xaml.cs`: working creation dialog, keyboard handling, file/template selection, folder input/picker, notifications, safe text opening.
- `src/CreateFile.App/Package.appxmanifest`: supported Explorer/COM registration, version and branding.

- `src/CreateFile.App/Assets/*`: Mint logo/icon variants (generated by `scripts/Generate-Assets.ps1`).
- `src/CreateFile.Cli/Program.cs`: real create/validate/presets commands and exit codes.
